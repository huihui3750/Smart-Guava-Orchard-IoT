# 智慧芭樂果園環境監控與自動灌溉系統

Smart Guava Orchard IoT System

## 專案介紹

本專案為物聯網課程專題，使用 ESP32 與多種感測器，模擬智慧果園的環境監控及自動灌溉功能，並透過 Wokwi 平台進行系統模擬。

## 主要功能

- 監測環境溫度與濕度
- 模擬土壤濕度偵測
- 依土壤濕度控制自動灌溉
- 使用超音波感測器偵測水位
- 透過 RGB LED 顯示警示狀態
- 支援自動與手動操作模式

## 使用技術

- ESP32
- MicroPython
- Wokwi
- DHT22、HC-SR04
- SG90 伺服馬達
- RGB LED

## 專案檔案

- `main.py`：感測器讀取與設備控制
- `diagram.json`：Wokwi 電路配置
- `README.md`：專案說明文件

## 執行方式

1. 開啟 Wokwi ESP32 MicroPython 模擬器。
2. 匯入 `main.py` 與 `diagram.json`。
3. 啟動模擬，觀察感測數據與灌溉控制結果。

## 專案說明

本作品源自大學物聯網課程團隊專題，主要用於學習 ESP32 感測器整合、自動控制與物聯網系統設計。

目前版本為重建示範程式，實際模擬運作結果仍待完整驗證。
