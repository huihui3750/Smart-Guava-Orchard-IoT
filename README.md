# 智慧芭樂果園環境監控與自動灌溉系統（重建示範版）

> **重要：這是依照課程專題報告重建的程式，不是原始程式碼。尚未在 Wokwi 實際執行驗證。**

## 使用方式
1. 開啟 https://wokwi.com/projects/new/micropython-esp32
2. 將本專案 `main.py`、`diagram.json` 內容分別貼入 Wokwi 對應檔案。
3. 執行模擬，調整 DHT22、可變電阻與超音波距離，觀察 Serial Monitor。
4. 4x4 鍵盤：`A` 自動模式、`B` 手動模式、手動模式下 `1` 開閥、`0` 關閥。

## 元件與接腳
ESP32、DHT22 GPIO15、可變電阻 ADC34、SG90 GPIO18、HC-SR04 Trig16/Echo17、RGB LED R5/G4/B2、鍵盤 Row13/12/14/27 Col26/25/33/32。

## 邏輯
- 模擬土壤濕度低於 40% 時自動開閥；這是可變電阻的模擬比例，並非實際校正的土壤含水率。
- 水位距離達 20 cm 或超音波讀取失敗時禁止灌溉。
- 溫度 >= 35°C 顯示黃色警示；水位不足顯示紅色，灌溉顯示綠色，待機顯示藍色。
- 手動模式也保留缺水保護。

## 注意
- 專題報告中有些功能屬架構規劃，這個版本**沒有**實作 MQTT、Firebase、React 儀表板或手機推播。
- Wokwi 零件與 MicroPython 韌體版本可能需要微調，尤其 RGB LED、ADC 與 PWM 的行為。
- 若接到真實硬體，HC-SR04 的 5V Echo 必須降壓至 ESP32 安全電壓，伺服馬達需合適的獨立電源及共地。
